# FUTURE_CS_02 - Phishing Email Detection & Awareness System

## Objective
Analyze phishing email samples, identify phishing indicators, classify emails, and provide security awareness recommendations.

## Tools Used
- Google Phishing Quiz
- Browser
- Canva
- GitHub

## Key Findings
- Identified 3 phishing emails and 1 legitimate email.
- Analyzed suspicious sender addresses, deceptive URLs, and social engineering techniques.
- Classified email samples based on risk and legitimacy.
- Developed awareness recommendations to help users recognize phishing attacks.
